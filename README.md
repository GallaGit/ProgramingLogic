## Que es este repo?

Un espacio personal para aprender **logica de programacion desde cero**, resolviendo ejercicios clasicos totalmente a mano. El objetivo no es copiar soluciones, sino entender el *por que* detras de cada algoritmo y grabarlo en la memoria muscular.

> [!NOTE]
> Todo el contenido teorico (explicaciones, contexto y desgloses) fue elaborado con ayuda de **NotebookLM** a partir de resumenes y consultas propias.

---

## Objetivos

- Programar totalmente a mano, sin copiar codigo
- Aprender y dominar la logica de programacion
- Tener en memoria muscular las resoluciones a problemas clasicos
- Llevar los ejercicios de consola al navegador

## Fuentes y recursos

> [!TIP]
> Los ejercicios estan basados en los retos de https://github.com/mouredev/mouredev, una coleccion de **101 ejercicios** clasificados por dificultad (facil, medio, dificil) que cubren desde algoritmos clasicos hasta conexiones con APIs.

| Recurso | Descripcion |
|---------|-------------|
| [Retos de Programacion](https://retosdeprogramacion.com/ejercicios/) | 101 ejercicios de logica por MoureDev, clasificados por dificultad |
| [Weekly Challenge 2022](https://github.com/mouredev/Weekly-Challenge-2022-Kotlin) | 52 retos semanales de programacion creados por MoureDev |
| [NotebookLM](https://notebooklm.google.com/notebook/adf591b8-a584-4a8d-a473-f254bca64f1b) | Notebook con resumenes y consultas usados para el contenido teorico |
