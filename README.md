## Que es este repo?

Un espacio personal para aprender **logica de programacion desde cero**, resolviendo ejercicios clasicos **totalmente a mano**. El objetivo no es copiar soluciones, sino entender el *por que* detras de cada algoritmo y grabarlo en la memoria muscular.

> [!IMPORTANT]
> El codigo de los retos lo escribes tu. La IA (o cualquier ayuda) solo sirve para **explicar conceptos y dar pistas**, no para pegar soluciones.

> [!NOTE]
> Todo el contenido teorico (explicaciones, contexto y desgloses) fue elaborado con ayuda de **NotebookLM** a partir de resumenes y consultas propias.

Abre el hub en el navegador: [`index.html`](index.html) — camino playful con botones hacia cada ejercicio.

---

## Objetivos

- Programar totalmente a mano, sin copiar codigo
- Aprender y dominar la logica de programacion
- Tener en memoria muscular las resoluciones a problemas clasicos
- Llevar los ejercicios de consola al navegador
- Practiar un mini proyecto con **frameworks y componentes**
