# Laberinto

**Nivel:** Dificil · **Estado:** Por hacer

## Enunciado

Representa un laberinto (matriz de celdas: muro / camino / salida).
Encuentra un camino desde la entrada hasta la salida
(o indica que no hay camino).

Puedes dibujarlo en HTML (grid) o trabajarlo primero en consola.

## Pistas (sin spoilear el algoritmo)

1. Matriz 2D: `0` = camino, `1` = muro, `S` = start, `E` = end (o coordenadas).
2. Muevete arriba/abajo/izquierda/derecha (4 direcciones).
3. Marca celdas visitadas para no entrar en bucles.
4. Busca ideas: recorrido en profundidad (DFS) o en anchura (BFS).
5. Extra UI: resaltar el camino encontrado celda a celda.

## Tu codigo

Este es un reto grande. Empieza por la matriz en consola; la UI despues.
