# Sucesion de Fibonacci

**Nivel:** Facil · **Estado:** Por hacer

## Enunciado

Imprime los primeros N numeros de la sucesion de Fibonacci
(0, 1, 1, 2, 3, 5, 8, 13…).

Decide tu: N fijo, o un input en el HTML.

## Pistas

1. Empieza con dos variables: `a = 0`, `b = 1`.
2. En cada paso, el siguiente es `a + b`.
3. Luego “avanza”: `a` pasa a ser lo que era `b`, y `b` el nuevo.
4. Un `for` o `while` te basta. Guarda los valores en un array si quieres mostrarlos.

## Tu codigo

Escribe todo en `app.js`.
