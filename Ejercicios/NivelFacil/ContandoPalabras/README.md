# Contando palabras

**Nivel:** Facil · **Estado:** Por hacer

## Enunciado

Dado un texto, cuenta cuantas veces aparece cada palabra.
Ignora mayusculas/minusculas y signos de puntuacion basicos.

Ejemplo: `"Hola, hola mundo"` → `{ hola: 2, mundo: 1 }`

## Pistas

1. Pasa todo a minusculas.
2. Separa por espacios (`split`).
3. Limpia comas/puntos de cada palabra.
4. Usa un objeto (o `Map`) como contador: si la clave existe, suma 1.
