# Anagrama

**Nivel:** Facil · **Estado:** Por hacer

## Enunciado

Escribe una funcion que reciba dos palabras y diga si son anagramas
(mismas letras, distinto orden). Ignora mayusculas/minusculas.

Ejemplos:
- `amor` y `roma` → si
- `hola` y `halo` → si
- `casa` y `saco` → no

## Pistas (no son la solucion)

1. Normaliza ambas cadenas (minusculas, quita espacios).
2. Compara si tienen la misma longitud.
3. Ordena las letras de cada una… o cuenta frecuencia de caracteres.
4. Si el resultado de comparar es igual → anagrama.

## Tu codigo

Escribe todo en `app.js`. El HTML solo sirve para probar en el navegador.
