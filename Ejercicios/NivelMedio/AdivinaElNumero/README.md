# Adivina el numero

**Nivel:** Medio · **Estado:** Por hacer

## Enunciado

La PC elige un numero secreto (ej. 1–100).
Tu intentas adivinarlo. Tras cada intento: “mas alto”, “mas bajo” o “correcto”.
Cuenta los intentos.

## Pistas

1. `Math.random()` + `Math.floor` para el secreto.
2. Compara el input del usuario con el secreto (`>`, `<`, `===`).
3. Un contador `intentos++` en cada intento.
4. Extra: limitar intentos maximos o un boton de reinicio.

## Tu codigo

Escribe todo en `app.js`.
