# Tres en raya

**Nivel:** Medio · **Estado:** Por hacer

## Enunciado

Crea el juego clasico 3x3. Dos jugadores (o tu vs PC).
Gana quien complete fila, columna o diagonal.

## Pistas

1. Representa el tablero: array de 9 celdas, o matriz 3x3.
2. Cada click coloca "X" o "O" y cambia el turno.
3. Despues de cada jugada, revisa las 8 lineas ganadoras.
4. Empate: tablero lleno sin ganador.
5. Extra: bloquear celdas ya ocupadas.

## Tu codigo

HTML = tablero. Logica = `app.js`. Sin bibliotecas.
