# Palindromo

**Nivel:** Medio · **Estado:** Por hacer

## Enunciado

Comprueba si una cadena se lee igual al derecho y al reves.
Ignora espacios, mayusculas y signos (opcional pero recomendado).

Ejemplos: `"anilina"` → si · `"hola"` → no · `"Anita lava la tina"` → si (si limpias)

## Pistas

1. Limpia la cadena (minusculas, sin espacios/puntuacion).
2. Compara la cadena con su version invertida… o usa dos indices (inicio/fin).
3. Si en algun punto los caracteres no coinciden → no es palindromo.
